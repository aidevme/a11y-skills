# Support

## How to get help

- **Bug reports and feature requests:** open an issue at <https://github.com/aidevme/A11Y-skills/issues>.
- **Questions and discussion:** use GitHub Discussions on the same repository.
- **Security issues:** do **not** open a public issue — follow [SECURITY.md](SECURITY.md).

## Support policy

This project is maintained by AIDevMe on a best-effort basis. Issues are triaged regularly; there is no guaranteed response time. Before filing, please check existing issues and `docs/` (especially `DESIGN.md` and `safety-and-guardrails.md`).
